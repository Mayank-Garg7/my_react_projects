# 🚀 SaaS Admin Dashboard + Real-Time Management System

A production-level frontend-focused project built using React.js that simulates a real-world SaaS admin dashboard with authentication, analytics, user management, and real-time features.

---

# 📌 Overview

This project is designed to showcase **2+ years of frontend development skills** including:
- Authentication system (JWT + OAuth concept)
- Role-based access control
- Real-time updates using Socket.io
- Dashboard with analytics
- CRUD operations with APIs
- Modern UI/UX design

---

# ⚙️ Tech Stack

- React.js (Vite)
- Redux Toolkit / Context API
- React Router DOM
- Tailwind CSS / Ant Design
- Node.js + Express (optional backend)
- MongoDB
- Socket.io
- JWT Authentication
- Axios (API calls)
- Vercel / Render (Deployment)
